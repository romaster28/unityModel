# Unity Base Model (No MonoBehaviour)

![Unity](https://img.shields.io/badge/Unity-2021.3+-black.svg) ![License](https://img.shields.io/badge/License-MIT-blue.svg) ![GitHub release](https://img.shields.io/github/v/release/romaster28/unityModel?label=Version)

**Unity Base Model** is a lightweight Unity package providing a foundational model structure without MonoBehaviour dependencies. Ideal for modular, performance-focused designs in games and simulations.

---

## ✨ Key Features

- **No MonoBehaviour**: Clean, script-independent base for extensible models.
- **Modular Design**: Easy to extend with future models and components.

---

## 📦 Installation

### Via Unity Package Manager (Git URL)
1. Open **Unity** and go to **Window > Package Manager**.
2. Click the **"+"** button in the top-left corner and select **"Add package from git URL"**.
3. Paste the following URL: https://github.com/romaster28/unityModel.git#develop
